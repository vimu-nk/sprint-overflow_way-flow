# apps/web

React 19 + Vite PWA serving all four roles.

- **Match `design/`**: the Designathon HTML exports are the implementation spec, and fidelity is judged.
- Routing: TanStack Router file routes in `src/routes`. `src/routeTree.gen.ts` is generated by the Vite plugin, so never edit it.
- Data: TanStack Query. The API is same-origin at `/api`: Vite proxies it in dev and the nginx gateway does in the stack.
- Styling: Tailwind v4 CSS-first (`src/index.css`, no `tailwind.config`). shadcn/ui components are added via `components.json` into `src/components/ui`.
- PWA: `vite-plugin-pwa`. The service worker must never serve cached `/api` responses as navigation. Driver and loader flows must work offline and sync on reconnect.
- Driver and loader screens are judged at phone width (~390px). Design mobile-first; the dispatcher gets the large-screen layout.
